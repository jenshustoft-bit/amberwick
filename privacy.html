PRIVACY POLICY

Last updated: 5 October 2026

This policy covers YouTube Machine, the private tool the owner uses to publish Amberwick and the owner's other YouTube channels, and this website.

Who uses YouTube Machine

Only the channel owner. The tool runs on the owner's own computer. It is not available to the public, and it does not collect data from viewers or other people.

What it accesses

When the owner signs in with Google, YouTube Machine asks for permission to:

  • Manage the owner's YouTube videos — to upload finished videos and set their title, description, thumbnail and scheduled release time.
  • View the owner's YouTube account — to confirm which channel it is connected to.

How the data is used and stored

The sign-in token from Google is stored only on the owner's computer and is used only to perform the actions above on the owner's own channels. YouTube Machine does not sell, share or transfer any data to anyone, does not use it for advertising, and does not send it to any server other than Google's own YouTube services.

YouTube Machine's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses the YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the tool's files from the owner's computer deletes everything it stored.

This website

This website uses no cookies, no analytics and no tracking.
